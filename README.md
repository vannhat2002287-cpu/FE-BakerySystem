# Sales-Management-System

Hệ thống quản lý bán hàng cho tiệm bánh (Fresh Bakery POS)

## Mô tả

Ứng dụng quản lý bán hàng dành cho thị trường Nhật Bản, bao gồm:

- **POS**: Điểm bán hàng
- **Inventory**: Quản lý tồn kho
- **Dashboard**: Thống kê, báo cáo
- **History**: Lịch sử giao dịch

## Công nghệ

- React + TypeScript
- Tailwind CSS
- Vite
- React Router

## Cài đặt

```bash
npm install
npm run dev
```
